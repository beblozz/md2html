# md2html

Простой конвертер Markdown в HTML на C++17. Учебный проект: читает `.md` файл и печатает HTML.

```
md2html input.md > output.html
```

## Что умеет

| Markdown | HTML |
|---|---|
| `# Заголовок` ... `###### Заголовок` | `<h1>` ... `<h6>` |
| `- пункт`, `* пункт`, `+ пункт` | `<ul><li>` |
| `1. пункт` | `<ol><li>` |
| блок кода в тройных обратных кавычках | `<pre><code>` |
| `` `код` `` | `<code>` |
| `[текст](адрес)` | `<a href>` |
| `![описание](картинка.png)` | `<img>` |
| `**жирный**`, `*курсив*` | `<strong>`, `<em>` |
| `> цитата` | `<blockquote>` |
| `---` | `<hr>` |

Символы `<`, `>`, `&`, `"` в тексте заменяются на безопасные (`&lt;` и так далее).

## Сборка

Нужен компилятор с поддержкой C++17 и CMake 3.16 или новее.

```
cmake -S . -B build
cmake --build build
```

Программа появится в папке `build` (на Windows с Visual Studio в `build/Debug`).

## Использование

Только HTML-разметка в консоль:

```
./build/md2html examples/example.md
```

Сохранить в файл:

```
./build/md2html examples/example.md > output.html
./build/md2html examples/example.md -o output.html
```

Готовая страница со стилями:

```
./build/md2html examples/example.md --page --title "Пример" --css ../web/style.css -o examples/example.html
```

| Опция | Что делает |
|---|---|
| `-o FILE` | записать результат в файл |
| `--page` | сделать полную HTML-страницу с `<head>` и `<body>` |
| `--title TEXT` | заголовок страницы (по умолчанию имя файла) |
| `--css PATH` | путь к файлу стилей (по умолчанию `style.css`) |
| `-h`, `--help` | показать справку |

## Тесты

В папке `tests/cases` лежат пары файлов: `имя.md` и `имя.html` с правильным ответом.
Программа `run_tests` конвертирует каждый `.md` и сравнивает результат с `.html`.

```
cd build
ctest --output-on-failure
```

или напрямую:

```
./build/run_tests tests/cases
```

Чтобы добавить тест, нужно положить в `tests/cases` новый `.md` файл и `.html` с ожидаемым результатом.

## Просмотр в браузере

В папке `web` лежит маленькая страница на React. Открой `web/index.html` в браузере,
выбери `.md` файл и `.html`, который сделала программа, и они покажутся рядом.
Нужен интернет, потому что React подключается по ссылке.

Файл `web/style.css` также используется для страниц, собранных с опцией `--page`.

## Как устроен код

```
src/
  main.cpp     разбор аргументов командной строки, чтение и запись файлов
  parser.cpp   блоки: заголовки, списки, код, цитаты, абзацы
  inline.cpp   разметка внутри строки: ссылки, жирный, курсив, код
  page.cpp     обёртка в полную HTML-страницу
  utils.cpp    маленькие функции для строк и файлов
tests/
  run_tests.cpp
  cases/
web/
  index.html, app.js, style.css
examples/
```

Парсер работает в два этапа. Сначала текст делится на строки и по первой строке блока
определяется его тип. Потом для текста внутри блока вызывается `renderInline`,
который регулярными выражениями заменяет ссылки, жирный и курсив.

## Что пока не работает

- вложенные списки
- таблицы
- курсив через `_текст_`
- строка вида `2 * 3 * 4` превратится в курсив
- ссылки не проверяются, поэтому чужие непроверенные файлы лучше не конвертировать для публикации

## Планы

- вложенные списки
- оглавление по заголовкам
- чтение из стандартного ввода
